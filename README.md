# PrateekDutta.in

A personal one-page portfolio, built using Tailwind CSS and custom HTML/CSS/JS, showcasing AI leadership, skills, and impact.

## 📁 Project Structure

- `index.html` - Main portfolio page
- `styles.css` - Page styling and layout styles
- `script.js` - Mobile menu + smooth scroll interactions
- `README.md` - Project overview and instructions

## Accessibility

## 🎯 Notes

- This portfolio is mobile-responsive and uses Tailwind CDN for utility classes.
- All core UX and interaction logic is in `script.js`.
